# Как вносить изменения

## Ветки и PR
- `master` — всегда рабочая; прямых коммитов нет (после настройки защиты ветки).
- Работа идёт в ветке `feature/<коротко-что-делаем>` (или `fix/…`, `docs/…`), от свежего `master`.
- Маленькие PR (до ~400 строк диффа), один PR — одна задача из Ёжки. В описании PR — ссылка/код задачи (например `MWMSCOR-12`) и что проверено.
- Ревьюит **другой** участник; без одобрения не вливаем. Вливаем squash-merge, чтобы в `master` было по одному осмысленному коммиту на задачу.

## Коммиты
Формат: `<тип>: <что сделано>` на русском или английском, в повелительном наклонении/настоящем времени.
Типы: `feat` (новая функциональность), `fix`, `docs`, `test`, `refactor`, `chore` (инфраструктура, зависимости), `ci`.
Примеры: `feat: приход партии и запись движения RECEIPT`, `fix: порядок блокировки товаров при резерве`.
Секреты (`.env`, ключи, пароли) не коммитим — никогда; если закоммитили, считайте секрет скомпрометированным и замените.

## Перед открытием PR (чеклист)
- [ ] Код работает локально, изменение запускалось руками (не только тесты).
- [ ] `ruff check . && ruff format --check . && pytest` (из каталога `backend/` с активным venv) — зелёное.
- [ ] Есть тесты на новое поведение, включая ошибочные сценарии.
- [ ] Миграция (если менялась схема): `upgrade`/`downgrade` проходят, CHECK-ограничения на месте.
- [ ] Документация обновлена: [API.md](docs/API.md), [DOMAIN.md](docs/DOMAIN.md), [DB_SCHEMA.md](docs/DB_SCHEMA.md) — что затронуто.
- [ ] Таблица статуса в [README](README.md) обновлена.
- [ ] Остатки меняются только через `modules/stock` (см. [ARCHITECTURE.md](docs/ARCHITECTURE.md)).

## «Готово» для задачи
Задача в Ёжке закрывается, когда выполнен критерий «Готово, когда» из её описания **и** PR влит. Если по ходу решили отступить от
документов — сначала поправьте документ (в том же PR), а не оставляйте расхождение.

## Если что-то непонятно
Правила предметной области — в [docs/DOMAIN.md](docs/DOMAIN.md). Если документ молчит или двусмысленен — допишите в него решение
и зафиксируйте в PR, чтобы следующий человек не гадал.
