# Warehouse Management System

Система управления складскими запасами (учебный проект, проектный практикум МТУСИ, БПИ2401).

Что умеет (целевой MVP):
- ведение **товаров, категорий, поставщиков и партий**;
- **приход** (приёмка) и **списание** продукции;
- **резервирование** товара под заказы;
- **инвентаризация** с автоматическими корректировками;
- **история движения** продукции (журнал, который нельзя править);
- **автоматическое выявление нехватки** запасов с рекомендацией закупки.

## Стек
Python 3.13 · FastAPI · Pydantic v2 · SQLAlchemy 2.0 · Alembic · PostgreSQL 16 · React + TypeScript + Vite ·
Docker Compose · GitHub Actions · pytest · ruff · зависимости — `pip` + `venv` (`requirements.txt`).

## Быстрый запуск
```bash
cp .env.example .env
docker compose up --build      # PostgreSQL + backend, миграции применяются при старте
# Swagger: http://localhost:8000/docs
```
Подробности и запуск без Docker — в [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
