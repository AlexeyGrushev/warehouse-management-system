# Warehouse Management System — концепция и дорожная карта

Система управления складскими запасами: товары и категории, партии и поставщики, приход и списание, резервирование,
инвентаризация, история движений, автоматическое выявление нехватки.

## Ключевые решения по домену
1. **Остаток не редактируется руками** — меняется только через движение (`stock_movements`: RECEIPT, WRITE_OFF, RESERVE, RELEASE, ADJUSTMENT). Отсюда бесплатно получается «история движения продукции».
2. **Партии**: приход создаёт партию (`qty_received`, `qty_remaining`, `unit_cost`, `expires_at`); списание идёт по правилу FEFO/FIFO (сначала истекающие/старые).
3. **Доступно = на складе − зарезервировано.** Резерв создаётся транзакционно (блокировка строк), имеет срок и статус (active / fulfilled / cancelled / expired).
4. **Инвентаризация** = сессия со строками «ожидали / насчитали»; при закрытии расхождения превращаются в движения ADJUSTMENT.
5. **Автодетект нехватки**: у товара `min_stock`; фоновая проверка и отчёт «доступно < min_stock» с рекомендуемым объёмом закупки.
6. Роли: `admin`, `storekeeper` (кладовщик), `viewer`.

## Сущности
users, categories (дерево), products (sku, unit, min_stock), suppliers, batches, stock_movements, reservations (+items), inventory_sessions (+lines).

## Правила работы
- `master` защищён: изменения через ветки `feature/<задача>` и PR; ревьюим друг друга.
- Коммиты: `feat: …`, `fix: …`, `docs: …`, `chore: …`.
- Задача в Ёжке закрывается, когда выполнен критерий «Готово, когда» из её описания.
